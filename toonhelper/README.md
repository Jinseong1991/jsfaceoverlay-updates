# 툰헬퍼 (ToonHelper)

소재 추천부터 콘티, 캐릭터, 시안 컷, 인스타 미리보기까지 — **서버도 API도 없이 HTML 파일 하나로 동작하는 인스타툰 서포터 프로그램**.
[docs/hits-reference](../docs/hits-reference/README.md)의 구조 분석을 그대로 구현했다.

## 바로 쓰기

`dist/툰헬퍼.html` 을 더블클릭하면 열린다. 와이파이를 꺼도 전부 동작한다.

| 탭 | 하는 일 | 참조 문서 |
|---|---|---|
| ① 소재 | 🎲 다시 뽑기, 슬롯 고정, 내 후보 추가, 최근·즐겨찾기 | 02 |
| ② 스토리 | 4/6/8/10컷 콘티, 대사·샷 편집, 컷 순서 이동, 대사 다시 | 03 |
| ③ 캐릭터 | 8명 랜덤 생성, 파츠·색 편집, 표정 7종, 주인공 지정 | 04 |
| ④ 시안 | 콘티 → 컷 자동 배치, 배경·표정·말풍선·효과·효과음, 4:5/1:1/9:16, PNG 저장 | 05 |
| ⑤ 미리보기 | 게시물 캐러셀·프로필 그리드 목업, 캡션 글자 수·해시태그 검사, 해시태그 추천 | 06 |
| AI | 프롬프트 복사 모드, AI 응답 → 콘티 반영, 내 API 키(BYOK)로 직접 호출 | 09 |
| 설정 | 프로젝트 내보내기/불러오기(JSON), 시드, 워터마크, 사용 설명 | 07·08 |

작업 내용은 브라우저에 자동 저장된다(선택값만 저장하므로 수 KB). 다른 PC로 옮기려면 설정 탭에서 프로젝트 파일로 내보낸다.

## 개발

```
toonhelper/
  src/
    index.html        UI 뼈대 (탭 7개)
    app.css
    app.js            상태 객체 하나를 모든 탭이 읽고 쓴다
    engine.js         조합 엔진 · 비트 시트 · 파츠 합성 · 캔버스 · 미리보기 · 저장 · AI 프롬프트 (데이터를 모른다)
    data/
      topics.js       소재 뱅크 (슬롯 6개, 후보 150+ , 템플릿 10, 해시태그 태그)
      beats.js        비트 시트 (4/6/8/10컷, 톤 6종, 역할→표정·연출 매핑)
      parts.js        캐릭터 파츠 (512 좌표계, 레이어 8, 표정 7, 팔레트 4)
      presets.js      코드로 그리는 배경 13종, 장소→배경 매핑
  build.js            src → dist/툰헬퍼.html (의존성 없음)
  test/engine.test.js 엔진·데이터 단위 테스트 (node --test)
  test/smoke.mjs      빌드 결과를 Chromium으로 열어 전 탭 동작 확인 (playwright 필요)
  dist/툰헬퍼.html    배포 파일
```

```bash
npm test          # 엔진 단위 테스트
npm run build     # dist/툰헬퍼.html 생성
npm run smoke     # (선택) 브라우저 스모크 테스트
```

개발 중에는 `src/index.html` 을 그대로 열어도 된다 (스크립트가 분리되어 있을 뿐 동일하게 동작).

## 데이터를 내 것으로 바꾸기

엔진은 작고, 결과물의 "작가 느낌"은 전부 `src/data/` 에서 나온다.

- **소재**: `topics.js` 의 슬롯 후보를 내 경험으로 교체·추가. `w` 로 가중치, `only` 로 어색한 조합 차단.
- **캐릭터**: `parts.js` 의 SVG를 내 그림으로 교체. 규칙은 04 문서 — 같은 viewBox(512), 얼굴 중심 (256,300), 색 치환 클래스 `c-hair / c-skin / c-clothes / c-accent`, 앞머리는 눈 위 레이어.
- **배경**: `presets.js` 에 함수 추가. 작가가 그린 PNG는 data URI로 넣는다 (외부 URL 금지 — 캔버스 오염).
- **콘티**: `beats.js` 의 `lines` 를 늘릴수록 반복이 줄어든다.

## 저작권

이 저장소의 소재 문장·파츠 그림·코드는 전부 툰헬퍼용으로 직접 작성했다. 참조한 HITS의 데이터는 포함하지 않는다.
