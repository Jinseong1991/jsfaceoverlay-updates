        프로젝트

        작업 내용은 이 브라우저에 자동 저장됩니다. 다른 PC로 옮기거나 백업하려면 프로젝트 파일로 내보내세요. (그림이 아니라 선택값만 저장되어 파일이 작습니다)

        같은 시드와 같은 순서로 뽑으면 같은 소재가 나옵니다. 재현이 필요할 때 씁니다.

        사용 순서

        1. 소재 — 🎲 다시 뽑기. 마음에 드는 슬롯은 고정하고 나머지를 다시 뽑습니다. 내 경험을 후보로 추가하면 결과가 내 것이 됩니다.
        2. 스토리 — 컷 수를 고르고 콘티 생성. 대사와 샷을 바로 고칩니다.
        3. 캐릭터 — 8명 랜덤 생성 → 마음에 드는 캐릭터를 골라 파츠·색을 조정하고 ★ 주인공으로.
        4. 시안 — 콘티에서 컷 자동 생성. 배경·표정·말풍선·효과를 만지고 PNG로 저장합니다.
        5. 미리보기 — 인스타 게시물·프로필 그리드로 확인. 캡션 글자 수와 해시태그를 검사합니다.

        작동 원리

        서버도 AI도 없습니다. 미리 써 둔 문장·템플릿과 그려 둔 파츠를 시드 난수로 조합합니다. 와이파이를 꺼도 전부 동작하며, 이 HTML 파일 하나가 프로그램 전체입니다.
