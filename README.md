JS Face Overlay update files

- [toonhelper/](toonhelper/README.md) — **툰헬퍼**: 위 참조 문서를 그대로 구현한 인스타툰 서포터 프로그램. `toonhelper/dist/툰헬퍼.html` 하나를 더블클릭하면 실행 (서버·API 없음)
