# 내 PC 그래픽카드로 Jinyu 그림 만들기

D 드라이브의 로컬 이미지 생성 도구(`D:\jsfo-gen`, Animagine XL 4.0)용 작업 목록이에요.
인터넷 서비스를 쓰지 않고 PC의 RTX 4080 SUPER로 만들어요.

## 실행
1. 이 폴더의 `jinyu.json`, `run-jinyu.bat` 두 파일을 `D:\jsfo-gen` 에 복사
2. 게임 등 그래픽카드를 많이 쓰는 프로그램을 끄기
3. `run-jinyu.bat` 더블클릭 → 끝나면 결과 폴더(`D:\jsfo-gen\out\jinyu`)가 자동으로 열림

## 만들어지는 것 (총 16장)
| 이름 | 크기 | 내용 |
|---|---|---|
| `jinyu_mascot_*.png` (+ `_cut.png` 투명 배경) | 1024×1024 | 민트빛 날개로 해를 향해 날아오르는 흰 새. 텔레그램 프로필, 마스코트용 |
| `jinyu_emblem_*.png` | 1024×1024 | 날개와 해를 단순화한 엠블럼 시안 |
| `jinyu_banner_*.png` | 1344×768 | 새벽 구름 위로 해가 뜨고 새가 나는 배너 |

색은 브랜드 색(밤 남색 → 새벽 파랑, 민트·청록 날개, 금색 해)에 맞춰 프롬프트를 썼어요.
이미 있는 파일은 건너뛰니, 다시 만들려면 파일을 지우거나 `jinyu.json` 의 seeds 숫자를 바꾸세요.

## 참고
- 이 모델은 애니메 그림체에 강해서, 글자가 들어가는 정교한 로고는 벡터 아이콘(`../icon.svg`)을 쓰는 게 좋아요.
  여기서 마음에 드는 그림이 나오면 그 느낌을 벡터 아이콘에 반영해 드릴게요.
