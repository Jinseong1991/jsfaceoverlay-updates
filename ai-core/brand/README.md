# Jinyu 브랜드

진성의 '진' + 자유(Freedom)의 '유'. 날개 달린 J가 떠오르는 해를 향해 날아오르는 모습이에요.

| 파일 | 용도 |
|---|---|
| `icon.svg`, `icon-1024.png`, `icon-512.png`, `icon-192.png` | 앱 아이콘, 텔레그램 봇 프로필 사진 |
| `favicon-32.png` | 브라우저 탭 아이콘 (웹 채팅 화면에는 이미 적용됨) |
| `logo-light.svg/png` | 밝은 배경용 가로 로고 |
| `logo-dark.svg/png` | 어두운 배경용 가로 로고 |
| `brand-sheet.png` | 아이콘, 로고, 색상 한눈에 보기 |

## 색상: 새벽하늘에서 날아오르는 순간
| 이름 | 값 | 의미 |
|---|---|---|
| Midnight Indigo | `#1E1B4B` | 깊은 밤하늘, 시작 |
| Deep Violet | `#3730A3` | 생각의 깊이 |
| Open Sky | `#0EA5E9` | 자유, 열린 하늘 |
| Aurora Mint | `#99F6E4` | 날개, 가벼움 |
| Sunrise Gold | `#FBBF24` | 진(眞), 빛나는 중심 |
| Cloud White | `#FFFFFF` | 순수, 여백 |

글꼴: Inter Display (Bold / SemiBold). 로고 SVG는 글꼴이 설치된 환경에서만 똑같이 보이니, 다른 곳에 쓸 때는 PNG를 쓰세요.
