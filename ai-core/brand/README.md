# Jinyu 브랜드

진성의 '진' + 자유(Freedom)의 '유'. J의 획이 그대로 끝이 뾰족한 날개가 되어 떠오르는 해를 향해 날아오르는 모습이에요.

| 파일 | 용도 |
|---|---|
| `icon.svg`, `icon-1024.png`, `icon-512.png`, `icon-192.png` | 앱 아이콘, 텔레그램 봇 프로필 사진 |
| `favicon-32.png` | 브라우저 탭 아이콘 (웹 채팅 화면에는 이미 적용됨) |
| `logo-light.svg/png` | 밝은 배경용 가로 로고 |
| `logo-dark.svg/png` | 어두운 배경용 가로 로고 |
| `brand-sheet.png` | 아이콘, 로고, 색상 한눈에 보기 |

## 색상: 새벽하늘에서 날아오르는 순간
| 이름 | 값 | 의미 |
|---|---|---|
| Midnight | `#0F0C2E` | 깊은 밤, 시작 |
| Indigo Dusk | `#25236E` | 생각의 깊이 |
| Open Sky | `#1667A8` | 자유, 열린 하늘 |
| Aurora Mint | `#8FF0DD` | 날개, 가벼움 |
| Wing Teal | `#4FD1C5` | 비상, 움직임 |
| Sunrise Gold | `#FBBF24` | 진(眞), 빛나는 중심 |

글꼴: Inter Display (SemiBold / Medium). 로고 SVG는 글꼴이 설치된 환경에서만 똑같이 보이니, 다른 곳에 쓸 때는 PNG를 쓰세요.
