# 03 · 스토리 · 컷 아이디어 (비트 시트)

## 원리 한 줄
인스타툰은 컷 수가 정해져 있다. 소재 한 줄을 **역할이 정해진 비트(도입·전개·반전·마무리)** 에 배분하고, 비트마다 **연출 힌트와 대사 템플릿**을 붙이면 컷 아이디어가 된다.

## 데이터 스키마

```jsonc
// beats.json
{
  "4": [
    { "role": "도입",   "goal": "상황 제시",            "shot": "풀샷",       "hint": "캐릭터 1명, 배경 1개, 대사 1줄",
      "lines": [ { "text": "오늘도 [장소]." }, { "text": "[장소]에 가면 늘 이래." } ] },
    { "role": "전개",   "goal": "문제·기대 발생",        "shot": "바스트샷",   "hint": "표정 변화 시작",

    { "role": "반전",   "goal": "예상 밖의 일",          "shot": "클로즈업",   "hint": "효과선, 큰 의성어, 배경 생략",

  "tones": {
    "공감형":    { "cuts": 4,  "lastHint": "'나만 그런가요?' 류 질문으로 끝내 댓글 유도" },

```

- `lines`의 `[슬롯]`은 02의 chosen 값으로 채운다. 즉 **소재 엔진의 출력이 스토리 엔진의 입력**이다.
- `shot`(풀샷/바스트/클로즈업)은 05에서 캐릭터 scale을 정하는 데 그대로 쓴다.

## 핵심 코드

```js
import { rng, pick } from "./02";   // 개념상. kit에서는 한 파일

export function storyboard(topic /* 02의 출력 */, beatsData, { cuts, seed = 1 } = {}) {
  const tone = beatsData.tones[topic.tone] || beatsData.tones["공감형"];
  const n = cuts || tone.cuts;
  const beats = beatsData[String(n)];
  const r = rng(seed * 31 + n);
  return beats.map((b, i) => {
    const line = pick(b.lines, r).text.replace(/\[([^\]]+)\]/g, (_, k) => topic.chosen[k] ?? `[${k}]`);
    return { cut: i + 1, role: b.role, goal: b.goal, shot: b.shot,
             hint: i === beats.length - 1 ? `${b.hint} · ${tone.lastHint}` : b.hint, line };
  });
}
```

출력 예
```js
[ { cut:1, role:"도입", shot:"풀샷", line:"오늘도 편의점.", hint:"캐릭터 1명, 배경 1개, 대사 1줄" },
  { cut:2, role:"전개", shot:"바스트샷", line:"어? 계산이 잘못 나왔다…", hint:"표정 변화 시작" },
  { cut:3, role:"반전", shot:"클로즈업", line:"알고 보니 내 착각이었다!!", hint:"효과선, 큰 의성어" },
  { cut:4, role:"마무리", shot:"풀샷·침묵컷", line:"나만 이래…?", hint:"여백 많이 · 질문으로 끝내 댓글 유도" } ]
```

## 인스타툰 구조 지식 (데이터 설계 시 참고)
- **썸네일(1컷)과 2컷이 결정적**: 2컷에서 공감이나 후킹이 없으면 넘기지 않는다. 비트 시트에서 "도입"에 후킹 문장 후보를 많이 둔다.
- **공유용 장표**: 요약 장표, 짤 장표를 의도적으로 마지막에 둔다. 톤별 `lastHint`로 반영.
- **캐러셀 최대 20장**: 컷 수 템플릿은 4·6·8·10, 표지 포함 최대 20.

## UI 패턴
- 컷 수 선택 (4/6/10) → 비트 배열 교체
- 컷 카드마다 "이 컷 대사 다시" (해당 비트만 재추첨)
- 컷 순서 드래그 (배열 순서 변경 후 cut 번호 재부여)
- "시안으로 보내기" → 각 컷의 `shot`과 `line`을 05 캔버스에 전달

## 응용 가능한 곳
릴스 대본(후킹→본론→반전→CTA), 블로그 글 구조(제목→문제→해결→요약), 광고 카피(문제→제품→증거→행동), 카드뉴스(표지→본문×n→요약). 비트 배열과 `lines`만 바꾸면 된다.
