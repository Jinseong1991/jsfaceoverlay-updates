# HITS 구조 참조 자료 (인스타툰 서포터 프로그램 분석)

호키스튜디오의 「호키툴 인스타툰 서포터 프로그램 HITS」가 "API 없이" 작동하는 원리를 공개 정보로 추정하고,
같은 구조를 내 프로그램에 응용할 수 있도록 **기능별로 분리한 참조 문서**입니다.

다른 세션에서 쓸 때는 이 README를 먼저 읽고, 필요한 기능 문서 하나만 열면 됩니다.
각 문서는 독립적으로 읽히도록 썼고, 코드는 외부 라이브러리 없이 브라우저 기본 기능만 사용합니다.

## 조사 근거와 한계

- **확인된 사실**: 상품명·가격(50,000원 → 35,000원)·설명문("웹용 서포터 프로그램", "소재 추천부터 시안 컷 생성")·광고 기능(캐릭터 생성, 스토리/컷 아이디어, 인스타 미리보기)은 판매 페이지 캡처에서 확인. 판매자는 캐릭터 표정·포즈 연습 가이드, 자만추북, 인스타툰 부스터팩 등 드로잉 자료를 아임웹 '유료 콘텐츠(다운로드)' 방식으로 파는 작가.
- **추정**: 파일 형식, 내부 코드, AI 모델 사용 여부는 확인하지 못함. 판매 페이지는 분석 환경에서 접속이 차단됐고 검색 엔진에도 색인되지 않음.
- **추정의 요지**: 단일 HTML 파일 + 브라우저 자바스크립트 + 작가가 만든 데이터(소재 문장, 그림 파츠). 생성형 AI 없이 "조합"으로 결과를 만든다. 근거는 01 문서 참조.

## 응용할 때 지켜야 할 선

- 원리·구조·알고리즘은 자유롭게 응용 가능.
- HITS의 소재 문장, 캐릭터 파츠 그림, 코드를 복사하는 것은 저작권 침해. 데이터는 반드시 직접 제작.
- 구매 시 이용 약관(재배포·역설계 금지 조항)을 확인.

## 한 줄 요약
